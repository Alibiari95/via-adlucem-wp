# via-adlucem-wp

Code for [via-adlucem.com](https://via-adlucem.com): an Archicon-inspired architecture-studio site built on WordPress with Elementor, Polylang (EN default, AZ, UZ, RU) and Contact Form 7.

## Layout

| Path | What it is |
|---|---|
| `wp-content/themes/via-adlucem/` | Child theme of **Hello Elementor**: header, footer, styles, scripts, custom Elementor widgets |
| `wp-content/mu-plugins/va-services.php` | **Services** custom post type (`/services/`), translatable with Polylang, built with Elementor |
| `wp-content/mu-plugins/va-projects.php` | **Projects** custom post type (`/projects/`) with project categories and tags, block-editor content |
| `wp-content/mu-plugins/va-auto-translate.php` | Auto-creates and machine-translates missing language versions of new projects (Claude or Google) |
| `wp-content/mu-plugins/va-deploy.php` | Deploys this repository onto the server (`va_deploy( $ref )` / `wp va deploy --ref=main`) |
| `content/i18n/{en,az,uz}.php` | Sample content per language used by the seed script |
| `content/services/{en,az,uz}.php` | Services content (from `services-pages-copy.docx`) and translations |
| `content/media/` | Real photos used by the services pages |
| `content/placeholders/` | Placeholder images in the brand palette (replace in the Media Library) |
| `tools/seed.php` | One-time setup: languages, Elementor kit, forms, pages, menus, Polylang strings |
| `content/projects/{az,en,uz,ru}.php` + `tools/seed-projects.php` | The projects (AZ is the source), categories, tags, menu item; re-running restores them |
| `content/ru/site.php` + `tools/add-russian.php` | Russian: language, home/contact/services pages (copies of the English pages with translated texts), form, menu, strings |
| `content/home/banner.php` + `tools/home-banner.php` | Full-width photo band between About and What we do on every home page |
| `tools/seed-services.php` | One-time setup of the 4 services × 3 languages, their SEO meta and menu entries |

## Theme

- Font: Space Grotesk. Colours: brand palette (navy `#003695`, orange `#FDAD34`, greys `#E6E5E3`…`#121110`) as CSS variables in `assets/css/main.css` and as Elementor global colours.
- Custom Elementor widgets (category **Via Adlucem**): **VA Hero Slider**, **VA Projects Slider**, **VA Accordion**.
- Helper CSS classes for Elementor (Advanced → CSS Classes):
  - containers: `va-section`, `va-section--tight`, `va-section--surface`, `va-section--dark`, `va-page-banner`, `va-services`, `va-counters`
  - widgets: `va-label` (small caps label with orange dot), `va-statement`, `va-statement--xl`, `va-lead`, `va-btn-outline`, `va-image-tall`, `va-reveal` (fade-up on scroll)
- Header/footer texts are Polylang strings: **Languages → Translations → group "Via Adlucem"**.
- Services: **Services** in the admin menu. Header image = *Header image* (featured image), subtitle = *Excerpt*, body = Elementor. Order = *Page Attributes → Order*. The overview at `/services/` and the "Other services" cards are generated automatically.
- Projects: **Projects** in the admin menu. Cover image = *Cover image*, summary = *Excerpt*, body = block editor (paragraphs, headings, images, galleries, quotes). The home page strip shows the newest projects automatically.
- Auto-translation: **Projects → Auto-translation** (service + API key). On first publish the other languages are created in the background; the *Translation* column shows the status, and row actions re-run it.
- Social links: **Appearance → Customize → Via Adlucem — social links**.

## Deploying

Every change is committed here first, then pulled onto the live site:

```php
va_deploy( '<branch-or-commit>' ); // run on the server (Novamira execute-php or `wp va deploy --ref=...`)
```

The deploy syntax-checks all PHP before installing, swaps folders atomically, then loads the home and contact pages as an admin and rolls back automatically if either fails.

Page content lives in the WordPress database. The first version of every page is generated by `tools/seed.php` from `content/i18n/`, so the site can be rebuilt from this repository; later edits made in Elementor stay in the database.
